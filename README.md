#Telecom Customers Data Analysis

## Project Overview

This project focuses on analyzing customer data for a telecommunications company using Microsoft Excel.

The analysis explores customer information such as cities, subscription plans, internet consumption, and billing amounts to extract useful insights and present the results in a simple and clear way.

## Project Objectives

The main objectives of this project are:

* Analyze customer subscription data.
* Identify the most commonly used subscription plan.
* Calculate the average customer bill.
* Find the highest and lowest internet consumption.
* Calculate the total internet consumption.
* Identify the customer with the highest internet usage.
* Determine which city has the highest number of customers.
* Present the results in an easy-to-understand dashboard.

##  Dataset

The dataset contains information about telecommunications customers, including:

| Column                    | Description                           |
| ------------------------- | ------------------------------------- |
| Customer ID               | Unique customer identification number |
| City                      | Customer's city                       |
| Plan Type                 | Customer's subscription plan          |
| Internet Consumption (GB) | Amount of internet consumed           |
| Bill Amount               | Customer's bill value                 |

## Tools & Technologies

* **Microsoft Excel**
* Excel Formulas
* Data Analysis
* Dashboard & Data Visualization

## Analysis Performed

The project uses Excel functions and formulas to calculate and analyze:

* Number of customers
* Average bill amount
* Maximum internet consumption
* Minimum internet consumption
* Total internet consumption
* Distribution of subscription plans
* Number of customers by city
* Customer with the highest internet consumption

## Key Results

Based on the analyzed dataset:

* **Most commonly used plan:** Basic
* **Highest internet consumption:** 210 GB
* **Customer with the highest consumption:** Customer 1014
* **Average bill:** 215
* **City with the highest number of customers:** Riyadh

## Dashboard

The project includes a dashboard designed to present the main findings of the customer data analysis in a clear and visual format.
